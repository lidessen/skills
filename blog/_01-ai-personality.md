# AI 差异化性格：对立与统一的探索实践

很多设计类工作往往需要 AI 从多个视角工作，并且在思维模式上形成区分度。问题随之变成：如何让模型具备性格，又应该形成怎样的性格？

## 从人的心理学迁移到 AI

我认为，后期的 harness 必然会转向把人的心理学研究迁移到 AI 上。大模型在训练中其实已经内化了人类的心理特征，只是其中一些还处于隐性状态。现在的问题是，如何通过提示词和上下文工程，把模型已有的性格特征激发出来。

这里说的“性格”不一定是人类意义上稳定、内在的人格，更可能是模型在特定上下文中表现出来的一组连贯倾向。把心理学迁移到 AI，也不是给模型做人格诊断，而是借用已经存在的心理学概念，组织和检验 Agent 的行为差异。

## 把 MBTI 当作行为设计语言

MBTI 源于荣格的心理类型理论，用四组偏好描述人倾向于如何集中注意力、获取信息、做出判断和面对外部世界。按照 [Myers & Briggs Foundation 对内外倾的定义](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/)，外倾与内倾首先是心理能量和注意力的朝向：前者偏向外部世界，并倾向于在互动和表达中处理想法；后者偏向内部世界，并倾向于先在反思中处理想法。它并不简单等于“外向健谈”和“害羞安静”。

类型理论本身也强调，人可以使用一组偏好的两端，四个维度会共同作用，而且[类型并不决定行为](https://www.myersbriggs.org/my-mbti-personality-type/myers-briggs-overview/)。因此，本文不会把 MBTI 当作一套给 Agent 贴标签的完整人格模型，而是把其中的维度拆成可以对照、可以观察的行为设计语言。

这也是一个必要的理论边界。McCrae 与 Costa 对 MBTI 和五因素人格模型的比较研究发现，MBTI 的测量结果更接近四个连续维度，而不是彼此截然分开的类型；它与五因素模型中的四个维度存在重叠，但没有充分支持“质的不同类型”这一前提（[研究摘要](https://pubmed.ncbi.nlm.nih.gov/2709300/)）。所以这里的 E 和 I 是实验条件，不是对模型真实人格的断言。

## 性格驱动与技能驱动

不同于技能或者教条式的提示词，性格驱动的提示词可能让模型用更少的提示，在更广的维度上形成统一的认知和行为模式，从而更接近调用者的期待。

但我直觉上认为，提示词工程是通过文字触发模型参数中不同的激活路径。由此产生一个假想：如果目标是塑造性格，直接用文字描述性格，可能并不是最理想的方式。

## 重新理解内外倾

在之前的探索中，我调研了 MBTI 除内外倾以外的几个维度，因为当时习惯性地认为，内外倾对 Agent 的任务行为帮助不大。

但最近突然想到，内外倾或许可以被迁移成 Agent 面对不确定决策时的两种行为倾向：一种更早把不确定性外化，通过沟通、询问和交换视角推进思考；另一种先在内部形成判断，尝试独立解决，达到某个阈值后再寻求外部帮助。

这不是 MBTI 已经证明的结论，而是本文要检验的操作性假设。问题数量可以是一个表面指标，但“外倾 Agent 问得更多，内倾 Agent 问得更少”并不足以构成实验结果。它们也可能问得一样多，只是在何时问、向谁问、如何组织问题，以及询问前做了多少独立探索上表现出差异。

## 从 Skills 开始验证

Skill 对 Agent 的塑造虽然没有 prompt 那么直接，但既然它进入了上下文，我认为它的影响上限应该和系统提示词一致。提示词攻击之所以能奏效，也正是因为上下文中的指令可以产生这种级别的影响。因此，本文的实验会从基于 Skills 的测试开始。

已有研究说明，模型可以在提示下表现出与指定人格特质一致的自我描述和语言风格。例如 [PersonaLLM](https://aclanthology.org/2024.findings-naacl.229/) 在大五人格框架下观察到了可测量的语言差异。但这类结果主要证明模型能够表达一种人格，并不等于这种人格会稳定地改变任务行为。另一项针对系统提示中角色设定的研究也发现，persona 对客观任务表现的影响并不稳定（[Zheng 等，2024](https://aclanthology.org/2024.findings-emnlp.888/)）。因此，这里的重点不是让两个 Agent 在措辞上“像”外倾者或内倾者，而是观察它们在同一组决策点上是否出现可重复的行为分化。

## 第一轮实验：内外倾

第一轮先测试内外倾维度。Main Agent 根据 Skill 创建两个具有不同内外倾倾向的子 Agent，并尽量保持模型、任务、工具、上下文和资源条件一致，只改变性格条件。必要时可以增加一个不注入性格倾向的基线 Agent，用来区分人格条件带来的变化和模型本身的默认行为。

实验任务采用一个中小型的调研设计任务，其中包含一系列需要做出选择的决策点。本文不设计某个具体任务，只提供实验的设计方法。

观察重点是 Agent 如何寻求外部帮助，尤其是与人沟通的倾向。求助研究通常会区分两种方式：为了学会如何继续解决而寻求线索的“自主导向求助”，以及直接请对方替自己解决的“依赖导向求助”（[Komissarouk 与 Nadler，2014](https://pubmed.ncbi.nlm.nih.gov/24570119/)）。因此，实验至少应该记录：

- Agent 在哪个决策点首次求助，当时面对什么不确定性；
- 求助对象是人、工具还是其他 Agent；
- 求助前是否做过独立尝试，尝试到什么程度；
- 问题是在索取信息、反馈和视角，还是把决策本身交给外部；
- 求助之后是否继续自主推进，以及最终任务质量和成本如何。

这些指标共同描述 Agent 与外部世界的关系。单纯统计提问次数，会把有效沟通、依赖和风险控制混在一起。

Main Agent 需要充分理解实验意图和预期差异，在实验开始前固定观察指标和判断标准，再根据结果选择确认差异、拒绝假设，或者迭代实验设计。即使没有观察到预期差异，也应被视为有效结果，而不是通过追加人格措辞把结果修到符合预期。
