# 视觉修辞：可组合的构图与搭配手法

2026-10-04 核对官方公开资料。以下名称是研究归纳，不是品牌官方分类，也不是保证
好看的公式。设计语言种子确定整体气质；这里提供在该气质内组织真实内容的手法。
原始文档有图或运行示例，制作时看适用的示例，不能只根据手法名称套样式。
需要直接试作阴影、配色、边框与动画时，读[表面与动效配方](surface-and-motion-recipes.md)，
包含参数起点和交互样片；本页负责组织关系，两者按当前缺口配合。

## 从缺口选手法

| 画面缺口               | 可尝试的手法   | 预期改变                         |
| ---------------------- | -------------- | -------------------------------- |
| 所有部分声音一样大     | 衬托、重点落笔 | 主体先被看见，辅助仍可读         |
| 内容像散落的组件       | 对偶、同域     | 重复关系形成轴线，同一对象有归属 |
| 整齐却呆板，或分隔太多 | 节奏、留白成组 | 有停顿但不断裂，不靠套框分组     |
| 少量文字被空地吞没     | 成块安放       | 内容形成完整形状，空白围绕它     |
| 读到最后不知如何结束   | 收束           | 解释、决定、操作与结果相接       |

选能解释当前缺口的手法，不必全部使用。用真实内容做局部试作，并带着上下文一起看；
先说明哪个关系预计改变，实际画面不支持时撤回。它们可以组合，但不要同时扩大每种
强调。下列边界与组合建议是研究推演，尚未证明在所有产品成立。

## 衬托：背景退让，主体保持清晰

**原型**：[Linear 2026 改版](https://linear.app/now/behind-the-latest-design-refresh)
的侧栏与边界前后图；官方调整外围竞争，同时保留工作区的信息密度。

**做法**：让导航、元信息与当前工作内容有明确的重量差异。用现有主题的字色、表面与
间距共同表达角色；弱化外围时，主体无需一起变淡。看视线是否更早落到正在工作的对象。
**反例**：全页浅灰、小字、细线；当前状态和操作也看不清。错误或选中不能为了安静隐去。
**搭配**：与重点落笔或同域配合；不要让导航、摘要、卡片、按钮都抢同一个重心。

## 对偶：稳定的标签—值或身份—动作关系

**原型**：[GOV.UK Summary list](https://design-system.service.gov.uk/components/summary-list/)
用键、值和有关动作组织事实；[Geist Description](https://vercel.com/geist/description)
展示标签与值的组合。

**做法**：让相同角色占据稳定阅读轴，值随内容生长；动作保持明确对象归属。桌面可以
横向对照，窄屏转为上下仍保留顺序。成对关系可用于身份/状态、标题/说明，不要求等宽。
**反例**：把无键值关系的任务硬塞进定义列表；短控件每行停在不同位置，空白没有形成
轴线；强制双列导致长值折得支离。不要复制示例固定宽度代替当前组合判断。
**搭配**：与节奏形成稳定列表；少量事实未必需要再套卡片。

## 节奏：重复建立预期，变化标出章节

**原型**：[Atlassian Spacing](https://atlassian.design/foundations/spacing)
的相似性、邻近、节奏与光学调整示例。

**做法**：同类条目重复行结构和停顿；同组内部更近，换组有更大的停顿。改变节奏时
对应新的内容角色，保留共同轴线。图标与文字重量不同时允许光学调整。
**反例**：所有间距相同，使标题像普通一行；每张卡片独立设间距；为打破单调无理由
轮换大小。尺度表只提供材料，不能替代分组判断。
**搭配**：与留白成组配合，保持密度也能有呼吸。

## 留白成组：空白也参与勾勒对象

**原型**：同上 Spacing 的邻近分组与层级示例；Linear 改版的边界对照提供另一种
减少外部轮廓竞争的做法。

**做法**：让一组内容的内部距离小于它与下一组的距离；观察整块的外轮廓与停顿。
先看去掉某条线后归属是否仍清楚，再决定是否保留。留白不是越多越好。
**反例**：仅删除所有边框；密集多对象丢失归属；内容在窄屏被巨大空隙推到下面。
**搭配**：与对偶、节奏组合。需要独立对象边界时，卡片仍可以是正确选择。

## 同域：共同表面把身份与内容连成一个对象

**原型**：[Geist Materials](https://vercel.com/geist/materials)将填充、轮廓、圆角与
阴影作为层次角色配合。它提供表面关系，不能由此推论所有编辑器都该有灰底。

**做法**：同一对象的标题、内容、动作共用表面或明确连续的轮廓；不同层级才增加
新的表面。展开后身份仍属于正在编辑的对象，表面变化要解释其角色。
**反例**：每个字段都加卡片；同色的大摘要与编辑面竞争；浮层阴影带进普通列表。
**搭配**：与衬托让当前对象突出，仍核对暗色主题的分离与焦点。

## 重点落笔：局部强调由真实内容获得资格

**原型**：[Atlassian Typography](https://atlassian.design/foundations/typography)
区分正文、标题和指标，并限制强调；它们与字色、间距一起工作。

**做法**：选择用户现在需要辨认的真实对象或信息，集中字重、尺度或色面对比。
标题和说明形成组合，其他内容退让；不是每页都需要大标题、指标或彩色徽章。
**反例**：把无关数字放大；摘要、标题和保存同时成为视觉中心；小号浅色解释承担
关键决定。字形与图标重量一起看，不用随机字体或装饰图标制造精致感。
**搭配**：与衬托配合。重要信息前置还要评估手机上占用的空间是否值得。

## 成块安放：整体定位与内部对齐分开

**原型**：[Carbon Empty states](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)
展示不同空间里的内容块位置、内部对齐、可选图像与下一动作。

**做法**：少量内容先形成标题、解释和必要动作的完整块，再决定这一块在可用空间
中的位置。整体居中不要求每行文字居中；配图形状和空间尺度共同决定布局。
**反例**：一句话漂在画面中；每个空区域都放大插图和主按钮；用装饰填满空地。
**搭配**：与重点落笔及收束形成完整空态。错误、无数据、无结果必须按真实原因表达。

## 收束：让最后一笔结束当前决定

**原型**：[GOV.UK Check answers](https://design-system.service.gov.uk/patterns/check-answers/)
在最终提交前组织复核内容和修改入口。迁移到局部编辑的收尾是本研究的类比，
不是要求每个表单新增复核页。

**做法**：必要影响说明与提交动作相接，动作归属于被修改对象；结果仍能看出改了
什么。局部编辑不让配置来源或其他辅助内容插在决定与提交之间。
**反例**：保存之后才读到重要影响；为了漂亮把必要说明折叠；把所有动作都做主按钮。
**搭配**：与同域收束编辑对象。保存、撤销、返回及反馈须实际操作，不能只看初态。

## 从素材到表达

### 几种可试作的搭配句式

以下是从上述关系提炼的制作起点，不是来源网站的完整皮肤，也不要求每页采用。

| 句式                  | 具体画面关系                                                                           | 适合与代价                                                           |
| --------------------- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 安静索引 + 当前工作面 | 重复身份行共用阅读轴，元信息跟随身份；展开对象获得连续表面，动作在表面末端收束         | 多对象逐一处理；平面行可能削弱独立对象边界，须让入口可辨             |
| 标题—说明—事实轴      | 标题和短说明组成一个开头，事实用稳定标签/值关系接续，动作靠近有关事实                  | 资料详情、复核与设置摘要；不适合逐段阅读正文，长值在窄屏须重排       |
| 成块的引导            | 标题、解释和一个必要下一动作组成紧凑左对齐块，整块安放于可用空间；有用图像围绕该块配合 | 空态或起步说明；多个区域重复此句式会争抢注意，不能造一个新主按钮填空 |
| 连续阅读 + 章节停顿   | 正文保持稳定行长和字级，标题以字重与组间停顿标出章节，回查材料沿固定轴安放             | 文献和长资料；不能把关键原文全部折叠换取短首屏                       |

最后一项是排版与节奏原则的迁移推演，未在本轮单独实测。表中各项都应由当前内容
重新制作：先用少量必要层次形成形状，再调整具体字号、色面和尺度。不要求增设摘要、
边栏或插图；现有内容足够时，就用现有内容把关系做完整。

手法是生成候选的材料，不是评分清单。用“哪个对象、哪种关系、哪种变化、哪项代价”
解释选择；再看画面有没有形成期望效果。必要时组合相容手法，但保留单一主导关系。
实际试作仍用 [构图与搭配试作](composition-craft.md) 收束，不能靠修辞名恢复失败产物。
