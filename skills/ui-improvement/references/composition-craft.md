# 构图与搭配试作

用于基础秩序已经成立，但画面缺少设计完成度；也用于自主扫描时发现各部件正确却合起来
没有气质的区域。参考对照见 [设计决定指引](design-language-guide.md#参考工艺对照)。
目标是培养可制作、可纠正的审美判断，不承诺人格描述能让模型成为设计天才。
需要具体制作素材时看[视觉修辞](visual-rhetoric.md)，按当前缺口选择手法及原始示例，
保持已有风格框架，不为了使用某种手法另换品牌。

## 先看见，而不是先找规则

在正常大小完整阅读页面，再看承担身份、内容、控制和收尾的区域。暂时不读源码，
说清视线先落在哪、随后去哪、哪里停顿或断掉；指出画面位置，不用“高级、简洁、精致”
代替观察。没有功能故障也要看：边框是否切碎同一对象，空白是否围绕主体形成形状，
字色是否有过多同等音量，重要内容是否像被剩余空间收容。它们是调查线索，不是必删项。

从任务选定希望形成的气质及视觉主角。例如长期阅读需要让文字连贯而有停顿；连接管理
需要身份、状态与修改结果相接；两者不必都安静到没有辨识度。让主体获得一种确切的
表达：清楚的排版轴、属于它的表面、可辨的轮廓或真实对象的视觉特征。辅助材料围绕它
配合，不用虚构数据、装饰标题、随机图标或大按钮制造重心。

## 用画面提出可推翻的诊断

选择最影响整体的一段关系，而不是列完所有 CSS 属性。写一个短假设：哪个表达导致
什么观感，改变后预计哪里会更好辨认或更协调。如果同时把所有字变小、颜色变淡、
间距压紧，却不能说明哪个关系改变，仍未形成解法。

参考只能提供候选；研究它怎样让同一对象连贯、不同角色有反差，以及细节如何相互
呼应。保留源码与画面的冲突和版本限制，不为了对齐一张旧图抹掉本产品的内容。
也不把当前源码合法当成审美不可修改：行为与数据合同限制什么可以改变，旧样式本身
不证明构图已经成立。

## 试作要产生认识

先区分必须保留的产品语言与可以重做的画面组织。字体、色调、对象身份和交互合同可以
延续，现有卡片嵌套、阅读轴和动作编排不因此成为保护对象。如果诊断指出整体组织欠缺，
方案却只调整 padding、字号和边框，检查是否绕开了诊断；参数修饰不能代替构图解法。

此时可在隔离样板中用同样的真实内容重新编排这一完整区域，暂时摆脱原 DOM 的便利：
先组织主体、辅助与操作的关系，再用已有组件实现。参考中选择一个确切的组织手法，
说明它解决什么关系，再转译到当前内容；不要只拷贝参数，也不要为显得不同另换品牌。
将这个试作与保守修饰放在相同状态下看，允许保守方案胜出，也允许两者都不够好。

对不确定的关系做有区分力的局部试作，连同所在完整区域一起看。可以先临时去掉某种
分隔，看对象更连贯还是失去归属；也可以改变阅读轴、表面层级或动作位置，看重心是否
清楚。临时去掉只是诊断手段，不是默认采用极简。仍缺表达时，另一候选应改变组织或
搭配关系，不只是换圆角或颜色。

内容、对象数量、必要动作和状态保持等价，避免删掉困难内容来赢得比较。用项目已有
字体、组件、资产和表面发展表达，允许有理由的角色差异；不以所有值相同为目标。
新的形式需要把标题、说明、输入、状态和收尾一起做完，不能只留下漂亮首屏。

回看正常大小的整屏，再看局部。确认视觉重量、疏密、空白轮廓和主体形态实际改变；
能用较少解释直接感知收益才支持保留。文字仍是文字，内容稀疏也能有构图；不能把
“更多留白”“更少边框”“更小字号”当成品质的单向尺度。对照没有明确收益，撤回这项
试作或重诊断，别给它换一套理由。

## 收束到一套搭配

选出成立的整体后，沿它的共同关系检查细节：标题与标签的声音，图标与字形的重量，
表面与输入的层级，外轮廓与内部留白，行长与组间停顿，展开与返回后的归属。只修破坏
这套搭配的细节，不把每个区域独立装修。明暗和窄屏允许重分配密度，主体与操作关系
仍需可辨；鼠标、键盘及触控目标不能因视觉紧凑失去可用性。

从参考借来的局部尺度要回到当前组合核对：短选项可以用短控件，但右侧空白应参与
排版轴、分组或邻接关系；若只是每行停在不同位置，参数虽合理，组合仍未完成。
同样，重要信息前移会占用空间，需回看它是否让常见任务更直接，尤其是窄屏。

交付实际前后画面和仍不满意的部分。自主诊断、制作手艺、参考还原、任务可用与用户
偏好分别判断；独立评审同意不等于用户接受。用户否定时，把产物留下作反例，找出是
诊断不够、表达未做到、评价误判还是偏好未知；不把一次否定机械译成新品牌规则。
