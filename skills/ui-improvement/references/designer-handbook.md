# 给新人的设计手册：从看见到做成

先把一页界面当成一件完整作品看。里面有人走动、有东西被使用、有文字被阅读，也
有变化发生。建筑、工业设计和平面设计提供了观察它的不同方式；最终都要回到具体
界面，不能让比喻代替制作。

这里的立场是：形式由多种关系共同形成，功能与美感都值得判断。材料配方已有来源
与样片，见[表面与动效配方](surface-and-motion-recipes.md)；本页是工作指导和教学
推演，不是设计史结论或效果已经证明的理论。

我喜欢用哲学追问一个选择的根据，但答案要能落到作品上。局部好看，放进整体是否
仍合适？统一之后，角色差异是否还清楚？功能已成立，美感还有哪些未完成？碰到
矛盾时比较具体方案的所得与所失，不先用“形式服从功能”或“审美是主观的”结束判断。
某种做法在一个情境成立，不证明它在另一个情境也该采用。

## 先安排相处方式

想象一个人进入页面。他要在哪里辨认方向，在哪里停下来阅读，在哪里作决定，做完
之后回到哪里？这些问题决定内容的邻接与尺度。需要反复比较的对象应容易相互参照，
修改结果应回到原对象，长期阅读应有连续的正文空间。

留白也是空间。它可以围合内容、让章节停顿、为操作留余地。先看内容形成什么形状，
再看空白怎样围绕它。把距离都放大，会像房间都很宽却没有可停留的地方；一味压紧，
又会让所有内容挤成同一种声音。

用真实标题、说明和动作摆出关系，暂时不靠投影与装饰补偿。主角没有明确位置时
先改编排；位置合适但表达平淡时，用字体与材料发展它，不强制推翻有效布局。

## 让表面说清使用方式

器物的把手、接缝与材料暗示怎样使用。界面的轮廓、表面高低、状态与反馈也参与
这种暗示。看卡片时，除了投影是否漂亮，也问它像静止内容、可选择对象，还是
正在被拿起的东西。决定了角色，再选阴影、描边和色面。

材料成组做：浅色浮层的投影与表面、暗色浮层的亮面与边缘，共同说明层次。字段、
内容面和外壳的圆角与留白要协调。每层再加框，可能让一个对象变成几个小盒子；
接缝可以成为表达，但应落在确实不同的职责之间。

颜色、质感与轮廓也能带来温度或性格。看它是否与作品相容，是否使表达更完整，
不要仅因删去后功能仍能运行，就认定该删除。同样，有名字、有参数也不证明值得保留。

## 让眼睛有路线

标题、正文、说明和动作组成一段阅读关系。先决定哪件事应先被认出，哪件事随后
解释它，再安排字重、字色、行长与停顿。字体家族保留，不等于字级必须保留；放大
标题也未必能解决主体缺失。

重复给人稳定感，变化标出角色。相同对象用共同阅读轴，标题与说明组成开头，章节
间留出不同于行间的停顿。安静仍应有主次反差，鲜明则让强调集中在真实内容上。

少量文字先形成完整内容块，再决定整块位置。整块居中不要求逐行居中；保留内部
左对齐，也可以让外形稳定、文字易读。实际看光学重量：图标盒子等大，笔画未必
等重；数学居中未必看起来居中。

控件像一件小器物，也有自己的组成。沿标签、当前值、箭头、边缘实际看一遍：文字
与箭头是否挤在一起，内外留白是否相配，字号与同排说明是否像同一套表达。使用
原生控件可以保留成熟交互，却不会自动带来完整视觉；在实际浏览器里看展开与焦点，
优先补足样式或复用已有实现，不因为外观欠缺就从头造一个下拉框。

例如一行有字段标签、短值选择框和跳转动作：先让值与箭头在框内相处，再把标签与框
的距离、文字基线和相邻动作一起调整。控件放大后，标签可能显得更弱，焦点外圈还
可能侵入标签留白；闭合态内部变好，不证明这一行已经协调。分别看内部与整组的
改前、改后画面，按最初症状判断收益，保留未解决的关系。它仍可以是原生 select，
也不要求所有行都做同高按钮；各角色应清楚，重量与间距需共同组成这一行。

## 把时间也设计完

展开要让人知道内容从哪里来，保存要让人知道改了什么，返回要让人重新找到位置。
先确定状态与动作的关系，再决定动画属性、距离、时间和曲线。短动作可以近乎即时，
较大变化可以给一点跟踪时间，尺度仍由用途决定。

过程和结果都看。一张展开终点可以漂亮，途中却把正文推来推去；成功反馈可以正确，
却出现在另一表单旁边。快速重开、取消与返回会揭露静态画面看不到的问题。减少
动态时也应知道发生了什么。

## 制作示范：把散落对象做成集合

设想页面展示几条连接，每条包含名称、模型、状态和编辑；展开后有字段、影响说明
和保存。这是教学情境，下面两种选择都可能成立。

用户反复比较模型时，可以试共同的身份—模型—动作轴，同行对象用重复节奏相连，
展开对象获得完整编辑面。每条连接有丰富、独立内容，需要分别辨认时，卡片可以
保留。决定来自对象关系，不来自“卡片过时”或“无框更高级”。

选连续列表后，先做真实文字与动作，让展开身份、字段、说明和保存属于同一对象。
再协调材料：静止行用轻分隔，编辑面用相容浅底，输入保留可辨边界，保存获得必要
强调。最后磨字形、空白、圆角和反馈，让局部沿共同关系完成。

回看代价：长名称是否让模型轴支离，窄屏是否该回到上下排列，无框动作是否太难
发现，编辑面是否过长，说明是否与操作相接。反例可以让你保留卡片或换组织。
桌面成立不等于窄屏也成立，参数相同不等于表现相同。

把窗口逐渐收窄，像看房间缩小后桌椅还能不能相处。几栏各自留下最小宽度，加起来
可能已经超过房间；外框没挤压，可能只是把最右边的操作推出视野。观察正文行长、
输入和动作实际能否容纳，再决定改列数或邻接关系。重排后也重新走一遍路线：原来
在栏内滚动的内容可能改为整页滚动，位置保存与返回不能只靠旧逻辑猜测。

读到一段话去记笔记，再回到那段话，是一个完整动作。只做“写笔记”入口，可能让
写完的人在长页里重新找原文。让人正常操作来检验往返；就近返回、并排或临时展开
都可试，按实际代价选择，不因“方便”就在每页再放一层悬浮控件。

## 用具体选择解释判断

新人可以先用普通话说明当前判断，不必填模板：

“同一个编辑对象被两层表面分开，身份看起来留在外面。我想让身份与字段共用一个
表面，保留周围条目的节奏。代价可能是打开后的灰面过大。做完要看对象归属是否
更直接，以及手机上其他对象和保存是否仍好找。”

这段话给出观察、制作决定与可推翻的预期。下一步去做，实际看画面。关系有改善，
再磨细节；关系没改善，回到选择本身。方向明确不必凑候选，无法判断才做有区分力
的对照。讲解让别人理解选择与代价，不替失败产物辩护。

交作品时保留实际画面和未满意部分。工具检查、操作观察、审美判断、参考还原与
用户接受各自有证据，互不代替；写出这份手册也不等于已证明新人或Agent制作更好。
