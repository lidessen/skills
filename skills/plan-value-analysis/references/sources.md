# 官方来源导航

这些链接只用于**定位本次核验入口**，不保存报价快照，也不代替逐字段证据。每次分析重新打开产品与 API 页面，核对适用地区、计费制度、更新时间、实际模型版本及扣费细则；把支持字段的 URL、抓取日期和短片段写入输入 JSON。若页面文字、表格、结账页或帮助中心冲突，记录冲突并停止该字段的精确估值。任何平台自身的 token/credit 定价都不能无证明地代替模型官方 API 价。
