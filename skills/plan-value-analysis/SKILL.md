# Plan Value Analysis · 套餐性价比

把**查询时仍在售**的套餐权益、模型扣费规则和该精确模型的官方 API 价格记入 JSON，由 `scripts/analyze.py` 计算。API 等值是取得相同模型用量的替代成本，不是现金返还或模型能力分数。所有派生数值与排序都来自脚本。

## 收集当前官方证据

1. 按地区核对各产品当前在售的档位、现价、年付和当前促销的首期与续费、税费、模型权限、原生额度及扣费规则。每次分析重新打开 [官方来源入口](references/sources.md)，记录查询日期、官方 URL 和支持字段的短片段。停售、过期、冲突或无法证实为当前权益的资料不进入榜单。
2. 核实厂商与产品身份、模型固定版本或服务 checkpoint、模式及对应模型的**官方** API 价。可变别名须先确认当次落点；同系列名称不等于同一模型。分别记录 input、output、cache read/write、长上下文、批处理等实际适用费率，token 桶不能重复计费。
3. 记录共享池与独立池、每模型扣费倍率、月/周/滚动窗口、有效期、限速并发、公平使用、超额费及客户端/API 权限。同一池的多种模型估值是互斥使用方式。短窗口不能按全天循环次数虚构月额度；即使还有官方月上限，它也只是月度价值上界，不能混入精确榜单。
4. 已按 input/output/cache read/write 分桶公布的 token 权益直接按对应官方费率换算；有官方 API 金额扣费口径的金额池直接按币种与扣费倍率换算。请求数、credits 或加权 token 池若没有完整官方映射，只用有来源的完整调用用量，或明确标记的**通用换算场景**计算，并展示假设和敏感性范围。一个操作可能触发多次模型调用；仅当这些调用使用相同模型、模式和 API 费率时才能合并为一条场景。额度、价格或扣费映射未知时用 `null` 并说明不可估值原因，不当作零。

## 计算与呈现

按 [输入契约](references/schema.md) 准备 JSON；[合成示例](examples/synthetic.json) 只演示格式，**不是现行报价**。正式输入的 `query_date` 须为执行环境当日，当前官方证据须同日复核。归档输入和输出可供查阅先前快照；以后运行正式榜单须重新取证、更新日期和输入。从本 skill 目录运行；在其他目录使用脚本的绝对路径：

```sh
python3 scripts/analyze.py INPUT.json --output RESULT.json --markdown TABLE.md
```

报告每档独立的月度订阅成本、API 等值及首期/续费倍率，保留原币种和限制：

- **同模型可比榜**：仅在精确模型、模式和适用 API 价相同的组内排序。
- **各模型自家 API 等值榜**：独有模型按本模型官方 API 价估值；数值不能解释为跨模型能力等价。

标出官方证据与换算场景的差别、可估值的上下界及未排名原因。请求或 credit 场景的结果取决于其 token 配比；共享池的各模型金额不能相加。只有短窗口额度时可报告单窗口诊断值；即使另有官方月上限，也仅报告月度上界，不把它当作保证可得的月度 ROI。
