# Personality evaluation

## 比较多个 Agent

共同目标和验收标准保持一致。比较人格贡献时，让 Agent 处理同一核心问题，获得等价材料
与工具；一个只调研、另一个只审校属于分工差异，不能据此归因人格。独立探索有价值时使用
新的独立上下文，不提前提供别人的答案、作者偏好或预期结论。
如果无法创建新上下文而让同一个 Agent 顺序切换人格，说明这不是独立视角的证据。

差异应落在注意了什么、如何比较、为什么推进或转向，而不是硬派一个赞成、一个反对。多位
Agent 得出同一结论不代表实验失败；独立检查不同理由后的一致同样是证据。不要按类型、票数
或“谁更像角色”裁决。

如果共同任务给不同 Agent 安排了不同侧重，必须标明“人格 + 分工的混合设计”。要检验人格
本身，就锁定任务文本和观察侧重，只改变人格材料。

## 综合结果

1. 先看交叉印证；两个独立视角命中同一处仍需自己核实。
2. 单一视角的观察先核实再采纳，无法核实就标为待查。
3. 区分事实错误与设计分歧：前者可以直接修，后者保留取舍并交用户决定。
4. 报告来源：亲自验证、多视角一致、单点观察或尚未确认。
