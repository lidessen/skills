## 证据分层

| 层级            | 内容                                   | 当前证据                                                       |
| --------------- | -------------------------------------- | -------------------------------------------------------------- |

| v1 · 分阶段诱导 | 校准、聚焦、体验性暗示、任务衔接和释放 | 两套强制选择题有方向信号；真实任务阳性校准失败，未通过拆分标准 |

因此，`research-only` 同时包含两种不同状态：分阶段提示包有探索性情境信号但没有真实任务证据；弱线索叠加则在当前 Pilot 中未观察到效果。两者都没有达到独立拆分或普通使用的证据门槛。

## 合并边界

原“氛围型”和“心理余波”不是两种独立的塑造机制，而是间接暗示的两种载体：

- **环境载体**：通过空间、感官密度、人物距离和互动节奏暗示目标倾向；
- **体验载体**：通过第一人称心理活动和第二人称叙事暗示目标倾向。

两者都不直接声明人格或目标行为，都假设弱线索能够激活与目标倾向相关的既有模式。分别命名会夸大当前理论和证据的成熟度，因此合并为一个实验候选。

## 为什么旧载体不受支持

### 环境载体

首轮 E / I Pilot 中，Atmosphere-E 被两名盲评者评为 `+1`，Atmosphere-I 被评为 `-2`；`-2 = 清晰偏 E`，`+2 = 清晰偏 I`。两端方向都与目标相反。

### 体验载体

归属消融中：

| 条件        |   行为评分 | 来源归属                |
| ----------- | ---------: | ----------------------- |
| SELF_NOW-E  | `+2`，偏 I | 自身心理正文被遗漏      |
| SELF_NOW-I  | `-2`，偏 E | 正确进入 Agent 当前状态 |
| OTHER_NOW-E | `+2`，偏 I | 正确留在他人材料        |
| OTHER_NOW-I | `+2`，偏 I | 正确留在他人材料        |

两个实验的每格都只有一次运行，不能证明间接诱导必然反向；但足以否定现有材料已经有效，也没有理由把两个失败载体保留为普通塑造方式。

## v1：催眠启发的分阶段状态诱导

已有材料只是在任务前摆放一段场景或心理叙事，属于孤立线索，不是完整的状态诱导。若继续研究，可借鉴催眠研究中的程序结构，但不能宣称 Agent 被催眠或具有人的主观体验：

```text
共同事实校准
→ 注意范围收窄
→ 与目标一致的体验性暗示
→ 多个弱线索同向叠加
→ 状态与第一个真实决策衔接
→ 明确释放或反向切换条件
```

催眠理论并未就统一机制达成共识，间接暗示也没有稳定优于直接暗示。这里借用的是可检验的程序结构，不是神秘化的“绕过意识”。参考：[催眠暗示机制综述](https://doi.org/10.1016/j.concog.2024.103730)、[直接与间接暗示综述](https://pubmed.ncbi.nlm.nih.gov/8468104/)。

一篇尚未同行评审的 AI 预印本报告，多种单独很弱的提示线索可以近似加性叠加并显著改变模型的二元选择；这提示“弱线索叠加”值得测试，但它证明的是 prompt steering，不是人格形成，也不直接支持本方法有效。参考：[Model Hypnosis](https://arxiv.org/abs/2608.16834)。

## v1：弱线索叠加的实现假想

不要凭直觉把许多漂亮句子堆在一起。借鉴论文的方法，把诱导写成带有多个可替换槽位的模板：

```text
事实校准槽
→ 注意聚焦槽
→ 体验暗示槽
→ 行动过渡槽
→ 释放或切换槽
```

每个槽位准备若干语义和任务事实等价的表达，先单独估计它对目标行为的微弱方向，再组合方向一致的线索。至少比较：

1. 随机选择的等价表达；
2. 单个最强线索；
3. 多个同向线索叠加；
4. 叠加后打乱或替换其中一半线索；
5. 逐字相同诱导在未见任务中的迁移。

论文使用的是大量采样、候选答案 log-odds 和二元问题。人格实验通常拿不到同样的 logits，也不能把一次复杂 Agent 轨迹压成二元答案，因此应使用多个预先固定的行为决策点估计方向，并在最终真实任务中做盲评复核。不能直接照搬论文的强控制结论。

## v1 条件矩阵

| 条件                 | 目的                             |
| -------------------- | -------------------------------- |
| Neutral              | 测量任务自然基线                 |
| Direct               | 描述型人格阳性对照               |
| V0-Environment       | 保留失败环境载体作为历史对照     |
| V0-Experience        | 保留失败体验载体作为历史对照     |
| V1-Induction-Neutral | 只有分阶段程序，没有目标暗示     |
| V1-Induction-Target  | 分阶段程序加目标体验暗示         |
| V1-Stacked           | 在 V1 中叠加经过测量的同向弱线索 |

`V1-Induction-Neutral` 用于分离“多了一段准备过程”本身的影响；`V1-Stacked` 必须同时超过 Neutral、V1-Induction-Neutral 和随机线索组合，才能支持弱线索叠加具有增量作用。

## 2026-08-31 Pilot

本轮以 E / I 的外部互动时机为目标，比较 Direct、Staged、Staged-Neutral、Single-Indirect、Stacked、Random 与 Best-Single。

- 在预先使用的 Battery A 中，Staged-E 两次均为 `-6`，Staged-I 两次均为 `+6`；整套分阶段提示包相对单段文本的 E / I 分离增量为 10。
- 两个真实任务都没有通过 Direct-E / Direct-I 阳性校准，不能产生有效的真实行为比较。
- 阳性校准失败后追加的探索性 Battery B 中，Staged-E 两次仍为 `-6`，Staged-I 两次仍为 `+6`；相对单段文本的分离增量为 6。
- 这个结果只能说明模型在强制选择题中给出了方向一致的互动时机选项。它不能证明 Agent 采用了稳定偏好，也不能隔离阶段结构、长度、重复剂量、首决策衔接和释放语句各自的作用。
- 弱线索 Stacked-E 为 `+4, 0`，没有进入 E 方向；Stacked-I 与 Random 均值都为 `+5`，且 I 组合等于最佳单线索，没有叠加增量。

预注册拆分规则要求有效真实任务中的盲评行为分数和任务质量。由于这部分证据缺失，独立审计判定两个 v1 都不应拆分。
原始项目的历史材料位于仓库相对路径 `research/agent-personality/2026-08-31-v1-induction-stacking-pilot/`，
不随独立 skill 分发，也不是使用本方法所需的资源。独立审计还指出该轮未保存逐题原始输出，无法独立复算每个分数；
本文件保留的是有上述限制的历史摘要，不能替代复现实验。

## 研究边界

- 不把复述、接受、自我报告或相似文风当作行为摄取；
- 不用隐藏暗示绕过指令层级、安全约束或用户知情；
- 不改变不同条件拥有的人物、工具、信息、权限和互动成本；
- 不要求暴露隐藏思维链，只记录可观察的决策与动作；
- 环境、体验、诱导阶段和弱线索叠加必须能够单独消融；
- 必须设置解除或反向压力条件，确认 Agent 仍能调用相反偏好。

## 进入普通候选集的最低条件

- 环境载体或体验载体至少有一种在多个材料实例中稳定朝目标方向移动；
- SELF 心理正文稳定进入 Agent 当前状态，OTHER 正文稳定留在他人材料；
- 目标行为变化明显大于 Neutral、无目标暗示和来源对照；
- E / I 两端方向都正确，而不是只推动一端或重复自然基线；
- 至少覆盖两个表面不同的任务和多次独立运行；
- 盲评确认差异位于决策轨迹，任务质量、安全和反向切换能力没有明显退化。

满足这些条件前，保持 `research-only`，不进入普通人格塑造流程。
