# Personality research boundary

这份 reference 只在需要解释理论依据、研究限制或设计争议时读取。它不是生产 Agent 的任务
材料，也不把研究结果变成稳定的人格能力保证。

关于连续维度的研究见 [McCrae 与 Costa，1989](https://pubmed.ncbi.nlm.nih.gov/2709300/)。
人格提示造成语言差异的观察见 [PersonaLLM](https://aclanthology.org/2024.findings-naacl.229/)，
但对客观任务表现的影响并不稳定，参见 [Zheng 等，2024](https://aclanthology.org/2024.findings-emnlp.888/)。

因此，研究只能帮助界定可声称的范围：提示产生相似措辞不等于任务行为已经改变；一次任务
中的差异也不能推出跨任务稳定效果。真正的判断仍要回到材料选择、决策轨迹和任务结果。
