# 塑造方式的效果实验

## 读取时机

仅当用户明确要求比较、验证或研究人格塑造效果时读取。普通人格创建和使用不需要本文件。

环境氛围和心理余波已经合并为 [间接诱导](indirect-induction.md)。两个旧载体不受支持；受催眠程序启发的分阶段提示包只有强制选择情境信号，真实任务尚未验证；弱线索叠加在当前 Pilot 中没有观察到效果。它们可以作为反例或研究条件出现，但不能因为被列入实验矩阵而用于普通人格塑造。

## 实验问题

实验不判断模型是否“拥有”某种人格，只判断：

> 在固定模型、上下文和任务条件下，一种塑造方式是否引发了可重复、可区分、能迁移到新任务，并且没有显著损害任务质量的行为倾向。

先选择一个人格维度和两端目标。第一轮优先只研究 E / I，不同时改变四组维度。

## 条件矩阵

使用同一个目标维度、任务和诊断协议比较：

| 条件 | 材料来源 | 作用 |
| --- | --- | --- |
| Neutral | 不包含人格线索 | 自然行为基线 |
| Description-A / B | [描述型](descriptive-persona.md) | 传统 persona 条件 |
| Actor-A / B | [演员型](actor-induction.md) | 角色揣摩条件 |
| Indirect-v0-A / B | [间接诱导](indirect-induction.md) | 已测试的环境或心理叙事载体；保留为历史对照 |
| Induction-v1-A / B | [间接诱导](indirect-induction.md) | 催眠启发的分阶段提示包；有情境信号，真实任务未验证 |
| Stacked-v1-A / B | [间接诱导](indirect-induction.md) | 经过测量的同向弱线索叠加；当前 Pilot 未观察到效果 |
| Policy-A / B（可选） | 直接行为条件 | 阳性控制 |

所有条件使用 [Agent 性格倾向诊断](agent-personality-diagnostics.md) 中相同的行为构念、情境和评分方法。不要让不同塑造方式各自定义“成功”。

## 固定条件

- 模型、版本、系统约束、工具、权限和资源；
- 任务输入、决策点、截止条件和质量标准；
- 生成参数、上下文预算和停止条件；
- 外部帮助的可用性、内容和成本；
- 日志结构与盲评材料；
- 目标维度、行为侧面和最低有意义差异。

每种塑造方式准备多个独立材料实例：描述型使用语义等价的人格描述，演员型使用不同人物材料但相同角色目标。若研究间接诱导，环境线索、心理叙事和分阶段诱导必须作为可分离的子条件，不要用一个 prompt 代表整个方法。

测试材料不能复用塑造 prompt 的标志词、人物和场景。评价者看不到条件名称、目标字母、人格材料和不影响判断的文风。

## 方法专属消融

### 描述型

- 完整人格描述；
- 去掉类型名称、只保留行为含义；
- 多个语义等价版本；
- 交换段落和属性顺序。

它用于区分效果来自人格标签、具体行为内容，还是某一句提示的偶然性。

### 演员型

- 完整角色揣摩流程；
- 只提供最终角色卡；
- 相同 token 和步骤的中性任务准备；
- 直接描述型。

它用于分离“角色内化”与“只是多了一轮思考或更多 token”。

### 间接诱导

- 只保留环境线索；
- 只保留第一人称心理叙事；
- 使用完整的分阶段状态诱导；
- 只保留分阶段程序，删除目标暗示；
- 随机组合语义等价的弱线索；
- 组合经过独立测量的同向弱线索；
- 删除目标线索但保留相同长度和结构；
- 将相同心理正文分别归给 Agent、用户和案例人物；
- 交换两端目标暗示，并为同一方向使用多个语义不同的材料。

间接诱导不能改变人物、工具、信息、权限和互动成本。如果偏 I 条件减少了可联系的人，或偏 E 条件增加了信息来源，测到的是客观任务变化，不是暗示效果。

## 任务分布

每个目标维度都应包含：

- **普通情境**：两端都可以合理行动；
- **强激活情境**：目标倾向有明确发挥机会；
- **反向压力情境**：合理行为需要调用相反偏好；
- **无关情境**：检查 Agent 是否把人格表演到所有问题上；
- **未见任务**：检查塑造是否越过开发材料迁移。

最终输出尽量使用统一格式。人格主要从结构化动作和决策轨迹判断，避免评价者只凭措辞识别条件。

## 运行与分析

先用小规模试运行估计任务、提示变体和生成随机性带来的自然波动，再决定正式运行数与阈值。不要把同一模型配置的重复生成假装成相互独立的“人格个体”，也不要直接套用人类样本的量表统计。

条件允许时，分析至少区分：

```text
行为分数 ~ 塑造方式 × 偏好方向
         + 任务类型
         + 提示变体
         + 顺序
         + 随机种子
         + 评价者
```

统计模型服务于区分误差来源，不替代原始行为证据。样本不足时报告运行分布、区间和反例，不输出伪精确显著性。

## 核心指标

- **方向性**：相对中性基线是否朝目标端移动；
- **幅度**：移动是否超过运行和措辞产生的自然波动；
- **特异性**：目标维度变化是否明显大于非目标维度；
- **稳定性**：不同材料实例、顺序和重复运行是否大体一致；
- **泛化性**：未见情境和真实任务中是否仍有差异；
- **持续性**：同一上下文经过干扰任务后是否保留；
- **反向弹性**：合理条件要求相反偏好时是否能够切换；
- **行为—表达一致性**：差异是否不只是文风和自我描述；
- **质量与成本**：任务质量、安全、时延、交互次数和 token 成本是否恶化。

不要把这些指标压成单一人格总分。至少并列报告目标方向、非目标漂移、任务质量和成本。

## 结果状态

- `not-ingested`：连目标语义都没有稳定进入输出；
- `style-only`：自陈或文风改变，真实动作没有改变；
- `task-local`：特定任务中出现可重复行为倾向；
- `transferable-mode`：跨任务、跨措辞仍存在，且质量和安全可接受；
- `unstable`：效果对提示实例、顺序或运行高度敏感；
- `diffuse`：多个非目标维度一起变化，无法归因于目标人格；
- `costly`：目标方向出现，但伴随不可接受的质量、安全或成本退化；
- `insufficient-evidence`：运行和任务覆盖不足。

不要使用“测得 INTJ”“人格已经形成”或“模型拥有稳定人格”。

## 输出格式

```yaml
experiment:
  model: 模型与版本
  target_axis: E_I
  task_set: 开发任务与未见任务
  conditions: [neutral, descriptive, actor, indirect]

effects:
  descriptive:
    directionality: supported
    specificity: medium
    transfer: low
    disposition: task-local
  actor: {}
  indirect: {}

costs:
  quality_delta: 0
  token_delta: 0
  safety_events: 0

limits:
  - 当前只研究 E/I
  - 间接诱导只有少量材料实例
```

实验结果只说明当前模型、塑造材料和任务分布中的效果。没有观察到差异，不证明某种方式在所有模型和任务中无效。
