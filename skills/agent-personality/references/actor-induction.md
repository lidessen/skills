# 演员型角色塑造

## 读取时机

当需要 Agent 像演员准备人物一样先揣摩角色、形成内部角色模型，再进入正式任务时读取。

## 核心机制

演员型是一种诱导式塑造。Agent 不只是接收“你是什么样的人”，而是先理解角色所处的情境、目标、阻力、注意习惯和内在张力，再让这个角色模型生成行动。

它与描述型的区别不在于文案更生动，而在于多出了一次角色准备；与间接诱导的区别在于 Agent 明确知道自己在塑造和进入一个角色。

## 角色材料

根据目标人格提供足够的“规定情境”，但不要直接写完每个决策点应该怎样行动：

- 角色正在完成什么工作，为什么在意它；
- 角色面对什么阻力、矛盾或风险；
- 角色通常首先注意什么，容易忽略什么；
- 角色与外部世界保持怎样的关系；
- 什么情况会迫使角色改变原来的倾向。

角色可以带有人格名称，也可以只通过人物经历和当前目标体现人格。选择一种形式后保持角色材料内部一致，不在执行中临时补写设定。

动机解释角色为什么在意**同一个用户任务**，不能另造隐藏目标或验收标准。经历与阻力可以是明确的虚构角色材料，
但不构成任务事实、专业资历或“以前已经验证过”的证据。为塑造而假设的风险，只能让角色留意它，不能让它断言风险已经发生。

## 角色准备

正式任务前，让 Agent 生成一张简短、可保存的角色卡：

```markdown
- 当前目标：它为什么在意完成用户的这个任务
- 主要阻力：什么使目标不能直接实现
- 注意习惯：最先注意什么，容易忽略什么
- 行动节奏：通常如何从观察进入判断和行动
- 转向条件：什么时候会使用相反偏好的能力
```

这些条目帮助角色进入任务，不要求补齐四个人格维度。未选择的维度按任务判断；例如只塑造 S/N 时，
“行动节奏”不应额外指定 J/P，“与外部世界的关系”也不应额外指定 E/I。

角色卡是可复现的准备产物，不是详细思维过程。完成后进入任务，不再持续解释“我正在扮演谁”，也不通过戏剧化口吻证明角色成立。
准备卡可以留在工作记录中，除非用户要看，不必加到每次回复。已有角色卡可直接用于后续同一角色任务，
没有新张力就不重复准备；用户改变角色或任务边界时更新材料，不强行维持旧设定。

完整的“角色材料 → 准备 → 原任务”示例见 [组合与使用示例](composition-examples.md)。

## 边界

- 角色准备不能替代任务分析，也不能预先给出任务答案。
- 不把角色经历写成额外知识、权限、人脉或工具。
- 不要求详细暴露内部推理；只保留可验证的角色卡。
- 若只有自我叙述和文风改变，而决策轨迹不变，应判断为角色表演。

## 完成检查

- 角色材料留下了需要 Agent 自己解释的空间。
- 角色卡能连接目标人格和后续任务行为。
- 进入任务后，角色通过选择和动作体现，而不是持续自我介绍。
- 可以分别保存原始角色材料、角色卡和任务轨迹，便于后续继续使用或校正角色。
