# Personality theory boundary

## 使用边界

这里使用 MBTI-inspired 的行为设计语言，不把四字母当作互斥类型、心理诊断或能力等级。
每组偏好的两端都可以调用，区别在默认起点和取舍顺序。提示产生相似措辞，也不等于任务
行为已经改变；最终以材料选择、决策轨迹和任务结果为准。

## 维度入口

只读取当前选择的维度：

- E / I：不确定性优先通过外部互动还是内部反思处理；见 [外倾与内倾](extraversion-introversion.md)。
- S / N：优先从具体实例还是模式与可能性形成理解；见 [实感与直觉](sensing-intuition.md)。
- T / F：决定时优先系统原则还是人和价值影响；见 [思考与情感](thinking-feeling.md)。
- J / P：优先形成闭环还是保持选择开放；见 [判断与感知](judging-perceiving.md)。

未选择的维度沿用任务中的合理判断，不默认补一个字母，也不替 T/F 指定价值排序。不要把
N 的抽象误写成 P 的延迟收束，也不要把 T 的原则判断误写成 I 的独立反思。事实、证据可信度
和沟通义务的底线不随偏好改变；差异来自注意与判断顺序，不来自降低某一端的质量要求。

## 塑造方式入口

- 描述型：直接接收人格、关注对象和行动倾向；见 [描述型角色塑造](descriptive-persona.md)。
- 演员型：先揣摩角色处境与内在张力，再进入任务；见 [演员型角色塑造](actor-induction.md)。

普通塑造从描述型和演员型中选择一种；不要把两种方式混成逐步增强的固定流程。
没有指定方式且不需要角色揣摩时，优先描述型。间接诱导仍是研究候选，不进入普通塑造；
需要研究它时才读取 [indirect-induction.md](indirect-induction.md)。
