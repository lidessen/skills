# Defrag report

报告服务于当前任务，不创建永久台账，也不复制源文件。按需要保留以下部分。

## Review

```md
范围：<本次检查的机制、概念或职责>
问题：<需要回答的问题>

已确认

- <对象>：<证据位置>；<残留/重复/分散/错位>；<实际负担>；<建议>

保留理由与未知

- 保留：<仍有效的消费者、行为或决策依据>
- 未知：<尚未确认的入口、外部依赖或运行时行为>

未决与重开条件

- <什么新证据会改变判断>
```

## Change

在 review 内容后补充：

```md
实际修改

- <文件或符号>：<语义变化和归属变化>

验证

- 机械：<格式、类型、静态检查或定向测试>
- 运行时：<实际打开、执行或观察到的行为>
- 用户验收：<已确认或尚未确认的使用结果>
```

只写本轮真实完成的内容。没有运行时或用户证据时明确说出，不用“测试通过”代替全部验收。
