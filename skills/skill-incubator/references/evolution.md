# 方法的遗传演进

用于需要大量候选、持续变异、跨轮次保留互补方法，并由 Agent 与用户分层选育的孵化。
简单修订继续直接做。这里的 DNA、遗传与显隐性是方法设计的类比，不是生物学模型或
已验证的自动优化算法；表达忠实、执行可靠和用户喜欢仍分别求证。

## 遗传什么，表达什么

先确定用户目标、不可擅改的合同、接受方向和实际环境。这些来自当前任务，不由选育
偷偷改变。可遗传的对象是方法关系：怎么看对象、怎样获得认识、怎样制作、怎样协作、
如何回应反证及收束。人格与哲学可以提供来源，但名称本身不代表能力。

将一份候选分成三个可辨认的层次：

| 层次       | 保存的内容                                         | 怎样判断有效                         |
| ---------- | -------------------------------------------------- | ------------------------------------ |
| 方法基因型 | 核心关系、前提、竞争方法、表达条件、反例及来源     | 是否改变真实选择，而非只换术语       |
| 表达       | 在目标环境中的工作流、skill/prompt、按需资料与交接 | 能否从关系恢复行动，前提是否真的可用 |
| 实际表现   | 观察、选择、修改、协作、结果与代价                 | 产物、实际操作、回归与独立接受       |

哲学层可以稳定而表达层变化。例如“部分通过整体关系获得意义”可转为：局部修饰
必须回到完整区域判断；共享修改要看有差异的消费者；多 Agent 的贡献要在合成版本
验证接合。它不是要求每轮重读哲学或扫描全产品。不能让理论名词替代这些工作关系。

一张短基因卡说明来源/父代、核心关系、适用前提、与父代的实质变化、怎样影响行动、
失效反例及证据状态。只在存在竞争方法时补表达控制，不要求所有卡具有全部字段。
卡是实验源，执行者获得它翻译后的冻结指导与任务，不必承担谱系和选育研究。

## 显性、隐性与组合

两个父代在同一个决定上提供不同方法时，保留这组竞争关系，并说明当前谁主导、
什么时候唤醒另一方法。隐性指本情境暂未表达，不表示较差，也不表示已经可靠。

例如 A 倾向恢复已有秩序，B 倾向重编构图。已有语言成立、问题局部时表达 A；参数
已正确但内容关系仍散、现有组织阻碍目标时表达 B。切换依据要来自画面与任务，不能
只是给“创新”更大的任意权重。未知足以改变选择时可分支试作，比较后再收束。

互补方法可共同表达或按依赖先后表达，例如独立观察之后汇合证据。真正互斥的方法
不能并列成两条必须指令，交由同一决定负责人根据前提选择，或用隔离分支检验。
找不到可辨的主导与切换条件，先保留两个候选，不为交叉硬造一个折中规则。

编译 skill 时，已选择的行为、触发分支与关键约束放在可发现的入口；较少使用的
替代方法按需展开。隐性方法若会改变下一步，就须有可找到的唤醒入口；没有当前
用途的储备留在实验材料中，不让每个执行者加载全部祖先。未加载/未触发/受能力
限制/表现失败分别记录，不能把没有表达算成通过。按原始任务判断适用性；适用却未
加载、未触发或误判切换条件，是当前可执行候选的失败，不从适用数中移除。只有本来
不适用才不要求表达；隐性储备不能事后成为逃避失败的解释。

## 走量靠短候选和多种变异来源

初期大量生成短基因型，少量翻译为完整指导，更少进行完整领域任务。批量规模是
本次实验预算，不能成为执行 Agent 的固定问题数、工具顺序或纠错轮数。
批次分别约定并报告生成、实质不同、已翻译、已使用、实际作品和用户可选产物的数量。
如果目标是大量UI试作，应让较多候选完成含真实内容和关键动作的局部作品，再少量
扩大到多页面；不能用一百张文字卡加两份作品宣称完成一百次UI演进。
按行动差别去重：若同一情境里对象、选择和下一动作都没变，换标题与人格不能充数。

可同时采用以下变异来源，再按实际后果调整生成资源：

- **局部变异**：改变一个工作关系，例如扫描单位、汇合时机、反馈取样或信息披露。
  便于解释，但不承诺一个关系必然有收益。
- **删减与抑制**：移除重复阅读、冗余角色或无依据门禁，保留必要合同，比较收益与退步。
- **从失败提炼**：从漏检、误判、交接损失或组合退步提出机制；不把本题坐标变成必改答案。
- **重新生成**：部分生成者只拿目标和环境，不读当前赢家正文，探索其他组织方法。
- **理论与实践移植**：将不同来源发展为行动关系，标前提、取舍和反例，允许来源失效。
- **交叉**：重组父代的互补关系，处理重叠、依赖和竞争表达，不拼接两份长文。
- **表达变异**：保持对象、关键判断、动作、责任和转向关系不变，改变措辞、呈现或
  不影响这些关系的信息组织，单独检验译法；改变上述关系就属于方法变异。调整顺序
  若改变了独立观察或关键选择，也不能只称文字翻译。

优先交叉已有局部证据且作用互补的父代；没有证据的交叉仍可探索，但标为假设。
子代不自动继承父代性能。特别检验组合的新增责任、信息负担、共享写入与验证接缝。
不能把所有赢家合成越来越长的唯一祖先。

变异器和翻译器也可改进，但与领域基因型分开版本。同一轮同时改变方法、译法、
预算和评估器只能支持混合观察，无法解释谁带来改善。普通表达纠正不算新的方法物种。

## 翻译成 Agent 能执行的指导

让翻译者接收冻结基因型、领域任务类别、实际环境能力和必要合同。形成默认入口、
对象与分工、判断分支、资料与工具入口、交接、完成和返回；不要求复制所有理论。
每个承重关系能在表达中定位，每个新增必做步骤有任务或方法依据。缺知识/制作手艺
时补有用资料，不能只把哲学翻成更强的角色形容词。

先核对表达是否遗漏关系、将条件改成普遍禁令、隐藏关键指导、默认创造工具权限，
或让两位 Agent 同时拥有共享写入/最终决定。纯格式检查只能发现机械问题；语义忠实
需要独立判断，实际是否有用仍须执行。

同一基因型表现不佳时，先区分译法失真、没有激活、工具能力缺失与方法本身无效。
关键判断不明可换一个译法短探针，不立即淘汰哲学，也不无限用“翻译不好”保护方法。
修译法或接合要有遗漏、误导或能力缺口的证据；哲学暂未被否定，不等于当前方法有效。
比较译法时固定基因型；比较基因型时尽量固定译法原则、环境与可用预算。

## 小轮次由 Agent 选择

先固定本轮目标、比较基线、任务材料、接受依据及资源上界。沿
[质量评估](quality-assessment.md) 用最便宜的充分证据分配试验：

1. **批量 L0**：检查实质差异、语义/依赖/接合缺陷，保留基线、互补分支和不确定探索。
   这是方法筛查，不是性能排名；少量看似弱或低分候选也可抽查，防止筛选器误杀。
2. **L1 短探针**：让独立执行者使用已翻译指导作出局部判断或交接，不给预期答案。
   给出可解释的失败和适用数，不用会讲道理代替发现与制作。
3. **局部实做/L2**：将关键未知转为实际修改、动作和产物；只扩大能改变选择的比较。
   保留原始条件、反例与合理差异，重看原症状、组合接缝及消费者。
4. **选育与下一变异**：按逐类结果和成本选保留、缩小、修译法、修方法或淘汰。
   被揭示的留出案例成为开发材料，补新的留出，不反复用已知答案宣称迁移。

保留逐任务族结果、整题合同是否成立、严重回归、误判/误阻断、虚假完成、协作损失
和实际成本。审美偏好与可靠性分开；漂亮不能抵消错误对象保存或不可用动作。
静态评分、多个同源评审一致与产物自评均不能作为唯一适应度。

新接线的回放工具或相互矛盾的结果也要核实：用已知行为检查对象定位、状态呈现和
比较时点；合法载体改变就适配可见操作入口，不把旧脚本假设当用户合同。评价器错误
保留原错报及修正依据，以同一接受语义复验，不将错报归给基因或为通过而缩小产品能力。

保留基线，以及在不同真实情境中表现有效的互补候选；不要只繁殖平均最高分的一支。
新颖性用有证据的行为差别判断，尚未执行的分支只称有差异的假设。各项结果不齐或
条件不匹配时保留未知，不输出虚假的稳定概率。界面越大、接合越多，越需要组合验证。

无新增有效差异、环境受阻或本批预算到达时，保存现有成果和下一未知。候选一时
没有胜出不要求机械繁殖；回到观察、参考或缩小问题可能更有收益。

## 大轮次交给用户

达到可比较的完整产物、出现方向取舍或本批研究边界时，提供少量代表候选。准备相同
内容/状态下的匿名画面、可操作预览、主要交互与已知回归、成本和取舍，不把几段 DNA
理论或自评分当作用户可评的设计。无有效候选时明确给基线与失败解释，不强迫择优。

Agent 已经在授权范围内筛掉有证据的错误、整合并验证；用户选择审美、价值排序和
方向，包括保留多个、选择混合方向、全不满意或保留基线。喜欢一张图不等于合同及
全面传播已验收。未解决关键缺陷可作为明确标注的探索方向展示，不称可靠赢家。

将用户选择保存为本任务的产物方向与偏好约束；方法父代仍依据冻结候选的逐类表现和
成本选择。可从喜欢的产物重新提出方法假设，不直接给产生它的整份DNA授予优胜。
展示已有跨案例结果及实际人工补救，不能把主 Agent 兜底的收益归给原候选。
不把一次偏好变成全局审美标准。
用户没有选择前不擅自宣布大轮次方向已接受；等待这一决定不妨碍不依赖它的检查。

## 在现有宿主中实现

实验侧只保存基因型/谱系、冻结指导、任务版本、产物与证据位置、选择理由及原执行
定位。Run、并发、权限、取消、恢复和费用边界使用实际宿主机制，不建第二份执行状态。
普通目录与一个简短批次记录足够起步；表达是实验源的派生产物，执行时固定版本。
冻结包括承重的按需资料和依赖方法，而不仅入口文字。宿主若按名字读当前目录，应
保存独立版本包、显式绑定必要依赖，避免排队/执行/原身份恢复时读取可改的共享祖先。
记录包路径和hash不等于runtime已提供内容不可变保证。

在交接中确认接收者实际可用的 skill 读取、工具、浏览器/图像能力、工作目录、预览和
并发。独立候选写入隔离副本；团队内部共享文件有唯一写入负责人，读可交叉。候选
之间隔离不等于团队内部无需协作。多 Agent 方法也应与适用的单 Agent 基线比较总成本。

若宿主支持独立任务批量提交，使用其公共接口有界派发；若只支持当前会话委派，用
现有创建/消息/等待能力组织短批次，不声称已得到无人值守系统。由支持委派的会话或
外层宿主实际派发独立执行；Runner没有子任务能力时，单Agent模拟角色对白不能算
多Agent基因已表达。独立诊断/评审任务只交原始目标、必要材料与表达，不默认继承
生成者的期望结论、评价或答案；评审实际作品时可隐去作者、谱系和自评。
并发参数只是上界，是否接纳以实际派发结果为准；暂受限可顺序完成独立贡献，不能
把模拟角色当作已派发。串行锁、目录互斥与共享浏览器会限制吞吐；大量排队不等于
大量有效执行。宿主没有总金额封顶时，不能
用作业数量或超时冒称严格费用保证。

可复用确定性脚本准备快照、哈希和公开材料，实际变异、语义翻译与选择由 Agent 作。
不为孵化增加动作 DSL、永久组织层或自动循环服务。实现新增工具要对应观察到的
重复负担；调度组合是否成立、技能/资料是否冻结要核代码与现场，不从接口名推定。

## 理论来源与证据范围

本方法将已有孵化/评估关系与外部研究相接，具体选育策略仍需本地验证：

- [Promptbreeder](https://arxiv.org/html/2309.16797v1) 演进任务提示和变异提示，为多来源
  变异与变异器自身反馈提供参考；原实验不证明 UI 方法基因型或显隐性有效。
- [GEPA](https://arxiv.org/abs/2507.19457) 使用执行轨迹反思、局部更新和候选保留，支持
  从具体后果修方法。跨模块组合仍需验证，不把论文实验收益复制为本地性能。
- [MAP-Elites](https://arxiv.org/abs/1504.04909) 按变化特征保留不同区域的优秀解，启发
  互补分支保留；我们使用少量可解释分支，不要求建立固定高维网格。

方法基因型、条件表达和哲学转译是这里提出的设计，不是假借这些论文的既有结论。
交付说明已经做到哪层、谁选了什么、依据是什么，尚未表达/实测的基因仍保留未知。
