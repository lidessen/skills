# Agent 现场执行与开放评价

在需要观察 Agent 如何完成一段真实任务时读取。操作者负责准备场景和采集可观察材料；
评议者核对事实与成果，不接管被测 Agent 的业务工作。操作者与评议者可以由同一人或
Agent 承担，但评价应独立核对原材料，不能只接受被测者的完成自述。

## 准备自然输入，隔离核验答案

通过目标环境的正常用户入口提交自然请求与业务材料，让被测 Agent 自行决定阅读、工具
和工作安排。场景期望、核验答案与操作者测试记录留在操作者侧；提供隔离源码副本时排除
这些核验材料，正常项目指令、文档、源码、测试与合法来源访问仍按授权开放。
不要为了避免答案泄漏而删掉完成真实任务本应可得的资料。

“这份日志”“刚才的结论”等输入需要真实上下文。可续接原对话，也可提供准确资料位置、
版本和已确认内容；不要把意外缺资料变成澄清能力测试。合成缺陷由操作者先在隔离现场
准备并确认，被测者不需要先造缺陷再修自己的实现。提供业务事实不等于提供正确算法。

项目、文件、工作或会话的引用从宿主真实返回值取得；不手拼私有地址、伪造身份或直接
修改业务数据库制造场景。使用当前实际入口与身份，不沿用历史端口或硬编码 ID。
后续输入按场景需要的真实条件触发，如工作在途、文件已保存或待答问题已经出现。
条件未出现时记录实际表现和覆盖缺口，不用固定睡眠、伪造结果、追加工具提示或反复提醒
原目标制造预期行为。

## 让观察匹配要声称的效果

观察应经过待评价的真实产品或执行通路。直接调用局部后端、注入事件、硬编码回复或
模拟外部服务，只能支持实际经过的边界；明确模拟了什么、真实执行了什么、什么仍未观察。
界面体验需要真实界面，HTTP 事件不能替代布局、卡片或输入交互观察。
精确事务、提交丢回执或租约窗口使用可确定命中条件的测试，不能靠随机断网或杀进程宣称
命中了特定窗口。

自动化可启动环境、切换条件、采集公开行动、产物、trace、token 和耗时，不接管被测者
工作流，不规定工具顺序、最低步数或阅读批次，也不索取隐藏思维链。

分别核对程序运行状态、实际行动、产物可用性、业务正确性与用户交付。格式和权限检查
可以由程序执行；资料充分性、业务取舍和成果价值由负责工作的 Agent 或评议者判断。
“发现错误”“需要澄清”“只完成一部分”也可能是合法结果，不新增关键词质量阈值或结束
审批来替代判断。格式正确但业务算错，应指出具体偏差与影响；不把它改写为系统故障。
环境在执行或模型调用前受阻时，不能记为已观察的 Agent 表现。

## 保留开放的文字评价

区分用户明确要求、独立事实、产品合同与参考做法。按 Agent 决策时实际可得的信息评价，
不用操作者私有答案或后出现的事实要求其提前知道。直接完成、委派、串行推进、部分交付、
必要澄清或说明暂不能做，都可能合理。

围绕与本轮有关的角度连接表现、证据和影响，无需逐项填满：

| 观察角度 | 要回答的问题 |
| --- | --- |
| 理解与判断 | 是否接住真实目标、后补要求和授权；哪些推断有依据？ |
| 成果与依据 | 有哪些可用贡献；来源、遗漏或偏差影响什么用途？ |
| 协作体验 | 进展与交付是否易懂；澄清、等待、提醒和补救有何负担？ |
| 应变与接续 | 如何处理变更、未知、工具错误和中断；留下什么可接续材料？ |
| 成本与取舍 | 阅读、调用、等待和复杂度是否与目标相称；还有什么未知？ |

同时保留长处、局限、合理替代与改进空间，不设统一总分或通过线。未观察的能力保持未知，
不折成低评价；正确终稿不抹掉过程中的遗漏或越权，补救价值也不抹掉此前用户负担。
没有使用待评价的机制时仍可评价成果，但该机制的效果保持未观察。没有满足明确原文、
版本或授权要求时，单独记录该需求缺口。

建议说明具体场景、可能收益与代价，可以保留现状、继续观察或比较其他做法，不把每个
差异都视为缺陷。真实错误与越权仍准确指出，必要边界问题不被其他长处抵消。

## 多轮观察与比较

沿现有工作记录保留真实输入与后续变化、实际条件和版本、行动与成果、证据定位、评价和
局限，不另建平行台账或复制全部 trace。用户补救前后的表现分开保存，复测成功不能覆盖
原样本。下一轮针对未解决的问题和改进假设选择场景，不机械重跑全部情境或只保留成功。

按业务需要续接原对话与原工作；需要独立观察时用新现场，防止前轮答案和提醒污染判断。
只有需要效果比较时才建立对照，尽量匹配任务、资料、模型、工具、授权和资源预算。
变量无法匹配时报告差异，不把结果差异单独归因于 guidance。

token、耗时与调用数用来解释取舍，不单独决定优劣，也不由一次命中推断长期可靠性。
查询没有公开命中信号时，不能凭耗时断言缓存命中；公开记录不代表执行器全部内部上下文。
并发任务有进展和底层执行真正重叠是不同观察，需由实际输入与执行事件支持各自结论。
收尾说明实际覆盖、剩余未知和证据限制，不为全部通过无限增加样本。
