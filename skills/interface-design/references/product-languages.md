# 产品语言研究：Apple、Vercel、Linear

2026-09-21。研究用户指定的代表性产品，不评价市场受欢迎程度。官方准则说明设计意图，不等于效果实证；本轮没有登录各产品执行真实业务。以下归纳是研究者的命名，不是品牌官方流派。

## Apple：以层次、材质和连续变化组织空间

来源：[HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。读取 HIG 材质正文与演讲文字中的 Dynamics、Adaptivity 相关内容，未进行原生应用实测。

官方区分内容层与承载导航、控制的 Liquid Glass 层，限制玻璃在内容中的使用。演讲将视觉与运动一起设计，而非先画静态玻璃再添加动画。

可迁移的关系：材质说明对象所在层次；动作与形态变化保持对象身份；输入方式影响反馈强度。可调的不只是透明度，还包括层的用途、背后内容、轮廓和运动的协调。

边界：玻璃不是 Apple 设计的全部，也不是任何内容都应使用的装饰。Web 的性能、文字密度和输入方式不同；不能用普通模糊阴影就宣称复现系统材质。清晰度与减少动态/透明度的替代必须参与设计。

## Vercel / Geist：将颜色与材质组织成语义角色

来源：[Colors](https://vercel.com/geist/colors)、[Materials](https://vercel.com/geist/materials)、[Button](https://vercel.com/geist/button)。读取三页相关正文；Computer Use 打开 Button，观察默认暗色页面的尺度对照并展开代码。只确认静态呈现和展开行为，未测量动画时长或 hover。

颜色按背景、交互状态、边框、文字等用途组织；材质把圆角、填充、描边和阴影组合成页面内与浮层角色。按钮页还明确区分产品常规用法与营销页面常用的圆形轮廓、阴影组合。

可迁移的关系：组件消费语义角色，配方协调改变角色对应值；不要让每个组件独立猜 hover 灰度或阴影。状态色和材质是组合规则，不是散落的数值。

边界：黑白不是全部色彩系统；营销页的视觉强调不应自动进入高频操作。公开文档有语境差异：通用指南建议提交前保持可用，Button 页允许在操作不可能时禁用。应按具体任务定义反馈与解释，不能把两句话拼成矛盾的全局规则。

## Linear：保留密度，减少外围竞争

来源：[2026 设计说明](https://linear.app/now/behind-the-latest-design-refresh)、[发布摘要](https://linear.app/changelog/2026-03-12-ui-refresh)、[2024 重设计过程](https://linear.app/now/how-we-redesigned-the-linear-ui)。读取两篇设计文章正文及发布摘要，未登录产品实测。

2026 调整导航、图标、边界与灰色倾向，并统一不同工作流的标题和控件位置。其主张是在保留密度的同时减少外围竞争。2024 对照中提高内容文字和中性图标的对比，说明弱化导航并不等于全界面变淡。

可迁移的关系：同类动作有稳定归属；内容、导航和元信息承担不同视觉重量。参数可以包括基础色、强调色和对比，但语法还包括信息与动作的位置。

边界：紧凑不是字号越小越好，低饱和不是灰到难读。这些文章不足以归纳 Linear 的加载、失败或撤销反馈系统，也不能证明动画速度。营销首页的宣传和演示不作为产品操作证据。

## 由案例推到可生成语言

以下是 2026-09-21 的探索模型，不是某个项目的现行规范。项目当前采用的主题与配置
回到该项目自己的约定核对。下表只用于理解语言的不同层次，不作为待实施路线图：

| 层       | 管什么                                 | 变化边界                |
| -------- | -------------------------------------- | ----------------------- |
| 语义基础 | 内容、操作、选中、焦点、进行、结果     | 换风格仍保留含义        |
| 构成语法 | 阅读主次、信息归属、层次、状态变化     | 不是只换 token 就能改变 |
| 风格配方 | 字体、密度、轮廓、材质、色彩、运动性格 | 成组协调，允许限定组合  |
| 场景表达 | 对话、列表、编辑器、浮层               | 保持关系，适应真实内容  |

前一轮提出的编辑式、工具式、空间式，只是工作分类，不是设计史公认分类，也不与三家公司一一对应。单一语法内可以参数化生成多种风格；跨语法变化可能涉及布局和组件结构。

当时提出的探索配方为精密平面、温和编辑、轻量空间，未成为当前标准主题。只有任务重新
开放设计方向时，才可将它们作为实验候选：保持相同任务和状态含义，改变密度、字级关系、
表面与运动。不要做三个品牌皮肤，也不要预设所有旋钮的任意组合都成立。
