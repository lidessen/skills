# 雕琢感与连续性：对动态样板的反证

2026-09-21。触发：用户认为 motion 样板不流畅、形式有批量组件拼装感。本次使用 Computer Use 重看约 1021×964 的页面并操作配方、模式切换与展开，结合源码检查。未采集帧时间、录屏或真实设备性能数据。

## 先修正前一轮推论

“几个基础语言加参数就能快速生成风格”需要前提：基础语言已经包含经过雕琢的构成与行为。若底层只是通用卡片，参数只能生成通用卡片的变体。

当前样板没有使用 shadcn；用户的类比指向视觉结果。不能把问题归罪于某个库，也不能把工业制造与低品质等同。问题是设计判断停在整齐和可配置，具体形式没有被充分推敲。

## 工艺不是反对工业：David Pye

[The Nature and Art of Workmanship 原书扫描](https://www.jonkolko.com/pdf/phd/pye_workmanship.pdf)。实际读取印刷页 20–26、61–64、128–132，非全书通读。

Pye 区分结果是否依赖制作当下的判断，并不据此评价好坏：确定性生产可以有高质量，风险性制作也可以很差。手工与机器不能说明判断发生在哪里。他讨论多尺度的丰富性，同时强调有序关系；粗糙和不规则本身不构成品质。

迁移推论：可复用组件和参数完全可以承载事先积累的细致判断。样板的问题不是可复用，而是尚未积累足够具体判断便开始推广。整体、对象、边缘和动作细节可以提供不同层次的发现，但必须相互支持。

边界：不借此要求每个控件独创曲线，不用随机延迟、噪点或抖动模拟手工；书中的空间尺度不能直接当成动画时间尺度。这是审美框架，不是软件性能或可用性的实验结论。

## 流畅是输入与响应的关系

[Apple：Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)。读取空间一致性、连续动态行为、性格协调及 tap/gesture 部分的官方文字。

可迁移：把交互设计成持续响应人的行为；按下及时回应，松开确认，允许改变主意；同一对象在不同入口下保持可识别的行为。动作路径、手势与反馈相互支持。

边界：这是实践框架，不证明某种 Web 曲线最优。其触屏压力和动量案例不能照搬为鼠标 hover 的强制形变。运动跟手、视觉平滑和帧率稳定需要分别核查。

## 数值一致与视觉一致不是同一件事

[Apple：Design for spatial user interfaces](https://developer.apple.com/videos/play/wwdc2023/10076/)，读取嵌套形状、间距和连续圆角相关段落；[Create custom symbols](https://developer.apple.com/videos/play/wwdc2021/10250/)，读取排版对齐、边距与尺度部分。

可迁移：近距离嵌套的轮廓与间距应有几何关系；图标的视觉重量和位置需要配合文字。几何居中、统一数字不自动产生视觉平衡。

边界：不能据此把所有圆角改成某种曲线，也不复制空间平台的具体间距。同心关系适用于实际嵌套轮廓，不要求页面每个圆角都由同一公式推出。

## 留白要参与构图

2026-09-21，用户指出附件预览像“白纸上随便写了几笔”。问题不只是元素少，而是标题、正文、辅助信息同重，空白缺少围绕主体组织的关系。

[大都会对王冬龄《Being Open and Empty》的作品说明](https://www.metmuseum.org/art/collection/search/77570)强调墨与纸面的相互作用：未落墨的纸面也是整体的重要组成。本轮读取馆方说明，未据此概括所有中国绘画，也不把书画的审美直接当作 UI 可用性证据。《道德经》第十一章的有无之用可作为哲学参照，但不能据此推导圆角或间距的数值。

迁移到界面时，将空白当作与内容同时设计的形状：它围绕哪个重心展开，在哪里聚拢相关内容，在哪里给阅读留出停顿，怎样引导人回到操作。疏密、虚实、主次、对齐共同起作用；统一 padding 或单纯放大边距不能替代构图。稀疏界面中的每个元素更显眼，因此字形、行距、边缘和细小的色阶更需要推敲。也不能用装饰性题签、印章或仿纸纹理来冒充这种关系。长内容、窄屏和操作密集时，应重新分配空白，不能为了保持画面清雅而藏掉必要信息。

## 尺度的秩序与光学校正

尺寸可形成有节奏的系统，但不是所有属性共享一个等比数列。字体按阅读角色选择少量层级，行高组织基线节奏；间距按组内、组间、区域边界选择尺度；图标按画布、实际轮廓、笔画与文字重量校准。数字相同不代表看起来一样大，数值规律也不证明审美必然成立。不要以黄金比例、斐波那契或“必须是 4 的倍数”替代具体判断。

参考 [Carbon 文字角色与尺度](https://carbondesignsystem.com/elements/typography/type-sets/)和 [Carbon v10 图标尺寸](https://v10.carbondesignsystem.com/guidelines/icons/usage/)：前者区分 productive / expressive，后者提供 16、20、24、32 等图标规格。这是实践系统的示例，不是普适心理定律，也不授权照搬整套品牌表达。本地 dialog 试验采用文字 12/14/20、行高 20/24/28、以 4px 为步长的间距档位，图标 16px 配 1.5px 笔画；保留光学校正空间，尤其关注中文字面、等宽代码、标点与图标内部空白的差异。

## 下一轮应改变的制作方式

先选一个真实对象和一段完整动作，例如“查看一次组件修改并展开比较”。围绕它推敲轮廓、排版、内容比例与收放方式，先做一个足够有说服力的实例，再提取值得复用的变量。通用性是从好实例里抽出的关系，不是提前取消具体判断。

比较时分离三个问题：构成是否有独特而合适的关系；动作是否跟手且有一致性格；设备上是否稳定呈现。对一个变量做局部对照，避免同时更换字体、布局、阴影与曲线之后只得到笼统偏好。

具体实验可以是：快速按下与较柔和释放的非对称响应；按钮表面形变而文字保持可读；升起、接触与光影使用同一状态协调；反向输入从当前状态衔接；真实内容下检查嵌套边缘和文字图标的光学平衡。

这不是要求统一物理引擎，也不是增加噪点、随机间距、装饰或更强回弹来模拟手工。理论帮助看见该判断的地方，不能代替判断本身。

后续作者作品研究修正：上述整块缩放、混合动画技术等属于待验证的具体问题，不能变成禁令。Emil 的示范也使用整块缩放；关键是幅度、响应、对象尺度与效果。完整反证和更广泛作品见 [作者作品研究](practitioner-studies.md)。
